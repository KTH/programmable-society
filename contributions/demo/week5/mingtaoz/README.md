## Description

This demo contrasts a public (vulnerable) token swap with a secret (protected) token swap, showing how confidential computing prevents a "Sandwich Attack".

**Relevance**

Confidential computing directly addresses one of the biggest hurdles for the smart contract security: privacy. Public blockchains are transparent, which is a feature (for auditing) but also a critical bug (for privacy). Many applications require privacy, e.g., exchanging, auctions, and private data sharing. Confidential computing provides a way to achieve privacy while still leveraging the benefits of blockchain technology.
