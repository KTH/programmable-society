## Description
Demonstration on how to use Web3.js and make transactions on a eth based blockchain.
The application will have a frontend and connect to a local chain using ganache.  
Steps :
  1.Set up a local Ethereum test network
  2.Initialize a JavaScript project
  3.Connect Web3.js to the local chain
  4.Load accounts and display balances
  5.Implement a simple transaction flow and call functions on a smart contract
  6.Show UI and Chain connection

## Relevance
Web3.js is a really popular framework to connect to a blockchain and an introdution to it will be useful for the final smart contract protocol development .
