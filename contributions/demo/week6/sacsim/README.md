On-Chain Verifiable Randomness: Demo with Chainlink VRF.

## Description
I will demonstrate how smart contracts can securely access verifiable random numbers using Chainlink’s Verifiable Random Function (VRF) to effectively power decentralized games, lotteries, or NFT minting mechanics. 

The demonstration will walk through deploying a contract that requests and receives random numbers from an oracle, and visualize how tamperproof randomness is crucial for trust in decentralized applications.

**Relevance**  
Chainlink VRF enables trustless, tamper-proof randomness essential for fair decentralized applications like games and lotteries. This demo showcases a key blockchain innovation that improves security and fairness by generating cryptographically proven random values on-chain.
