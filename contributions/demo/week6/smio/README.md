## Description

Dune is an application used for monitoring contracts in blockchain.
Today, we will demonstrate how blockchain analytics tools (Dune) can monitor, detect, and prevent risks in smart contract systems, using a betting contract as the live case study.

Today, dune will be used to monitor:

1. Total bets placed
2. Active liquidity in the betting pool
3. Win/loss distribution
4. Contract balance over time
5. Participant count

**Relevance**

Nobody wants to have the only way of interacting with a smart contract through code and calls. Such an application can be used by new users of a smart contract in order to get insight of it's functionalities, as well as other people's interaction with it.
