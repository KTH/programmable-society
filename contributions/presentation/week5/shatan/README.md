## Title

VRust: Automated Vulnerability Detection for Solana Smart Contracts

## Names and KTH ID

- Shangxuan Tang (shatan@kth.se)

## Deadline

- Week 5

## Category

- Paper/Book Presentation

## Description

This presentation introduces VRust, the first static analysis framework specifically designed for detecting security vulnerabilities in Solana smart contracts. VRust automatically identifies eight critical vulnerability patterns unique to Solana's stateless programming model - including missing signer checks, owner validation, integer overflows, and cross-program invocation risks.

**Relevance**

This work directly addresses smart contract security and verification, and demonstrates how automated static analysis can effectively secure smart contracts in next-generation blockchain platforms like Solana.
