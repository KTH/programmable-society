## Description

This presentation will explore VerX, the first automated verifier able to prove functional properties of Ethereum smart contracts. VerX addresses the software engineering challenge of verifying complex, project-specific logic. This presentation will cover the background, some challenges and the methodology of solving these challenges. 

**Relevance**

Automated verification is directly relevant to the "Use and improve software engineering for smart contracts" topic, as it is part of the software engineering techniques. Being able to verify guarantees about smart contract function properties helps moving the quality assurance process towards more formal verification.
