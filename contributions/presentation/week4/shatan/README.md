# Assignment Proposal

## Title

Rust as a Smart Contract Language: Safety, Reliability, and Real-World Adoption

## Names and KTH ID

- Shangxuan Tang (shatan@kth.se)

## Deadline

- Week 4

## Category

- Presentation

## Description

This presentation explores why Rust is becoming an important language for smart contract development. I will explain the language features which make Rust suitable for writing high-assurance, low-bug smart contracts. And I will also introduce representative rust-based ecosystems like CosmWasm (Cosmos), Anchor (Solana), and Commonware.

**Relevance**

This presentation continues the discussion on smart contract languages by showing why Rust is increasingly used in blockchain development. It also naturally sets the stage for the next session on smart contract libraries and tooling.
