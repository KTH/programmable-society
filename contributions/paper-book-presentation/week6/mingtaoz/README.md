Blockchain CAP Theorem Allows User-Dependent Adaptivity and Finality

## Description

The CAP theorem in the context of blockchains asserts that no protocol can simultaneously offer both adaptivity and finality. The paper proposes a new blockchain protocol, called the checkpointed longest chain, that offers individual users the choice between finality and adaptivity instead of imposing it at a system-wide level.

**Relevance**

This work is highly relevant to the blockchain infrastructure domain. It is a new consensus protocol that allows users to choose between adaptivity and finality, which is a significant advancement in blockchain technology.
