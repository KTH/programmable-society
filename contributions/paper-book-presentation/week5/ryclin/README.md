# Assignment Proposal

## Title  
Securing Smart Contracts in the Post-Quantum Era: A study of Quantum-Resistant Authentication for Blockchain Systems

## Names and KTH ID

## Category  
- Paper Presentation  
- Reference Paper: https://doi.org/10.1371/journal.pone.0302325 (2024)

## Description  
This presentation examines emerging security challenges posed by quantum computation to blockchain systems, focusing on how smart contracts can adopt quantum-resistant authentication and signature verification mechanisms.

Building on the reference paper, the presentation will introduce the threat that quantum computers pose, and then explore a proposed smart contract authentication scheme combining lattice-based digital signatures and cross-chain identity validation. It will highlight key technical components of the BSCTQCAT protocol, including its identity agent layer, heterogenous chain authentication flow, and experimental performance evaluation on digital-signature operations.

**Relevance**  
Quantum-resistant cryptography is becoming increasingly central to blockchain security, as quantum computers threaten commonly used cryptographic primitives like ECDSA and secp256k1. Understanding and evaluating quantum-safe authentication mechanisms is increasingly essential for ensuring the long-term security, reliability, and societal trust of smart-contract systems. 

Hopefully, by exploring how emerging quantum technologies reshape foundational security assumptions, we will be poised to make a smoother transition to post-quantum security standards.
