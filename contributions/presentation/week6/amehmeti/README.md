## Description
I will make a presentation about crypto “whales,” meaning wallets that move very large amounts of cryptocurrency. I will explain how these big transactions can be identified using publicly available blockchain data, and how whale activity influences the blockchain infrastructure itself, for example by affecting gas usage and overall on-chain activity patterns.

**Relevance**
This is relevant to the week’s theme because whale activity affects blockchain infrastructure, can be analyzed through on-chain data, and is something monitoring tools often track.
