## Description

This demo presents how blockchain analytics can be used to understand and monitor smart contract activity. I first demonstrate the basic use of Dune Analytics to explore on-chain transactions and contract interactions. I then introduce a small analytics component I developed for a simple DAO governance contract, including queries and visualizations for proposals, voting behavior, and execution outcomes.

**Relevance**

The demo aligns with the course topics on blockchain infrastructure, monitoring, and governance. It illustrates how real-world tools like Dune support transparency and security by enabling inspection of smart contract behavior.
