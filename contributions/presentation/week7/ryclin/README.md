# Assignment Proposal

## Title
Quadratic Voting in DAOs: Beyond one-token-one-vote

## Names and KTH ID
- Randall Lin Yi Cong (ryclin@kth.se)

## Deadline
- Week 7

## Category
- Presentation

## Description
I will present how quadratic voting mechanisms may address the plutocracy problem in DAO governance by making voting power non-linear with token holdings. The presentation will explain the mathematical foundation (cost=votes^2) and demonstrate why this optimizes collective decision-making. 

If possible, this presentation also aims to cover real-world deployments (e.g. Gitcoin Grants' quadratic funding mechanism) and alternative governance models like conviction voting and futarchy. 

**Relevance**  
Current DAOs tend to have an overwhelming inequality in token distribution, so this represents a one possible innovation for improving token-weighted governance systems by encoding social choice mechanisms for more democratic/egalitarian decision-making.
