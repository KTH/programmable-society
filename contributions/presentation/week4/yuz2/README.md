# Assignment Proposal

## Title

The Bedrock of DeFi: Why We Use Smart Contract Libraries like OpenZeppelin

## Names and KTH ID

- Yu Zhang (yuz2@kth.se)

## Deadline

- Week 4

## Category

- Presentation

## Description

This presentation will explore the critical role of smart contract libraries in modern blockchain development, focusing on OpenZeppelin as a primary example.

It will cover the following key points:

- Why libraries? The "Don't Reinvent the Wheel" principle in an immutable environment.
- Core concepts: How libraries like OpenZeppelin help prevent common vulnerabilities (e.g., Re-entrancy, overflow).
- Code examples: A look at how to build a secure ERC20 token or an Ownable contract in just a few lines of code by inheriting from the library.

**Relevance**

This topic is directly relevant to the "smart contract libraries" and "engineering" portion of the course. It provides a foundational understanding of how robust, secure, and complex applications are built by composing audited, reusable components rather than writing everything from scratch.
