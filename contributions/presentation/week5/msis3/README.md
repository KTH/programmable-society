## Description

I will present the Re-Entrancy Attack, explaining how repeated external calls can drain a smart contract before its state is updated. I will show why this vulnerability matters and how secure patterns like Checks-Effects-Interactions prevent it. I will also introduce a small original idea: a simple “Re-Entrancy Risk Score” for quick risk assessment.

**Relevance**

Re-entrancy is a well-known vulnerability that can drain smart contracts. Knowing it is key for building secure and reliable blockchain applications.
