## Description
Cairo is a programming language designed for provable computation. By combining Cairo with STARK proofs, we can build L2 solutions that process transactions off-chain while maintaining Ethereum-level security. This presentation explores:
 - the L1/L2 scalability problem, 
 - how Cairo enables provable computation, 
 - how STARKs provide verification at scale



 - Relevance
 - Since verification is the theme, I thought Cairo and stark would be a good topic as they change how transactions are verified on networks like Starknet . Instead of every node verifying by re-execution, verification happens through proofs which is faster .
