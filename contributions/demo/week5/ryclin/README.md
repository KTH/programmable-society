## Description  
This demo will feature a walkthrough of real-world smart contract vulnerabilities, drawn from Capture the Flag (CTF) challenges on Ethereum. I will demonstrate and explain how subtle mistakes in contract logic (e.g. improper authorization) and other classic EVM pitfalls can be exploited by attackers.

By solving CTF flags in a controlled environment, I will show:
- How common vulnerabilities work and exploit scripts for actual attacks
- Defensive techniques applied after each demonstration - illustrating how to patch/redesign code to prevent these threats

**Relevance**  
This demo is directly aligned with the security theme of week 5 and meets the criteria for a technically rich, engaging presentation.
- Live exploitation and (hopefully) remediation steps
- Bridges theory and hands=on practice
- Uses open-source/available resources from speedrunethereum that they can try out for themselves
