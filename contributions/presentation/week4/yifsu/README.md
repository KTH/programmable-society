# Assignment Proposal

## Title

Introduction to Foundry — a fast toolkit for Ethereum smart contract engineering

## Names and KTH ID

- Yifan Su (yifsu@kth.se)

## Deadline

- Week 4

## Category

- Presentation

## Description

This presentation introduces Foundry, a modern, high-performance toolkit for developing, testing, and deploying Ethereum smart contracts. Starting from motivation and ecosystem context, the talk will cover Foundry's core components (forge, anvil, cast, chisel), key features, and concrete developer workflows.

**Relevance**

This presentation aligns directly with the topics of "smart contract development tools" and "engineering" for the week 4. It provides practical insights into how Foundry enhances the smart contract development experience, enabling developers to write, test, and deploy contracts more efficiently and effectively.
