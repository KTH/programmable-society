## Title

[Gap Between Theory and Practice: An Empirical Study of Security Patches in Solidity] from ICSE 2020

## Deadline

## Category

## Description

This paper shows how Ethereum smart contracts adopt security-critical Solidity compiler patches. By analyzing a large number of deployed contracts, the paper reveals that most contracts rely on outdated tool, leaving known weakness unpatched in production systems.

Relevance

Understanding how developers adopt secure compiler updates is important. This gap can lead to avoidable vulnerabilities. Improving the situation would strengthen the security of blockchain systems.
