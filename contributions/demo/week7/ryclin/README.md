## Description  
This demo is a walkthrough for a decentralized, privacy-preseving on-chain voting system inspired by the ZK Voting challenge from SpeedrunEthereum. The goal is to illustrate how zero-knowledge proofs can be applied to governance mechanisms in blockchain systems, enabling anonymous but verifiable decision-making. Concepts/elements covered include: 
- commitments and nullifiers to create one-person-one-vote model
- how proposals are created and stored on-chain
- how votes are submitted using zk-style proofs (or their simplified equivalents)

**Relevance**  
This demo directly supports the Week 7 topics of Governance (Voting, DAO) & Art, by presenting a core governance primitive - voting - but implemented with privacy-preseving cryptography. This leads to greater fairness, resistance to coercion, and overall trust in decentralized decision-making.
